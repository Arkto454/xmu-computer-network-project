# S07 之后的前端进度（截至 2026-11-19）

此目录汇总 S08—S16 期间的最新前端源码及开发、验收记录。此前各阶段目录继续保留为历史版本。后续开发以本目录的 `miniprogram` 为此仓库内的最新版本入口。

## 使用

微信开发者工具导入本目录下的 `miniprogram` 文件夹，不要导入整个仓库。源码保留本机当前版本，未在上传副本中修改业务逻辑或配置：`config/env.js` 当前为 `real`，接口地址为 `http://127.0.0.1:18080`，需要另行启动兼容后端。仅查看演示时，可把该文件的 `MODE` 改成 `mock` 并重新编译。手机上的 localhost 不指向开发电脑。

未包含 `project.private.config.json`；开发者工具会生成各自的本地配置，基础库版本请按工具实际可用版本选择。本目录不含后端运行副本、密钥或数据库密码。
