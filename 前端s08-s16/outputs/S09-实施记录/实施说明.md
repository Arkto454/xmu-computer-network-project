# S09 实施说明

## 范围

任务大厅 P01 继续使用固定 Mock 数据，没有新增真实网络请求，也没有假定后端分页游标或接口路径。

## 实现

- 按任务类型筛选，并支持最新/最早发布时间排序。
- 首屏、下拉/按钮刷新、加载更多、空态、翻页失败、刷新失败和重试分别处理。
- Mock 服务按筛选与排序绑定游标；页面对合并结果按任务 ID 去重。
- 类型/排序变化会重置页码。筛选代次与请求序号会丢弃更早请求的迟到结果。
- 刷新失败保留已有列表；翻页失败保留先前任务。
- 公开任务摘要仅包含白名单字段，不携带本次联系方式或私密交接说明。
- 列表卡片直接使用页面原生 WXML，点击事件把 taskId 传给详情导航。
- 修正小程序运行时不支持目录式 `require('../../services')` 的入口，改为 `require('../../services/index')`。
