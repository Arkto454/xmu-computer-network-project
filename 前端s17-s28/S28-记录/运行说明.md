# 学生端运行说明

## 打开哪份代码

继续开发时使用你现有的主工程；交给其他同学审阅时，解压《学生端阶段源码-20261127-S28.zip》，在微信开发者工具中导入其中的miniprogram文件夹。project.config.json沿用项目AppID，其他同学须已加入该小程序的开发或体验成员。工具可以生成自己的project.private.config.json，不必复制你的私有配置。

现有验证环境为微信开发者工具Stable v2.01.2510260、基础库3.17.5；这些是已测版本，不代表必须安装的唯一版本。原生小程序，无需在前端安装npm包。使用普通编译，先等实际页面出现；此前模拟器启动曾需约7—15秒。

## 真实模式

1. 打开config/env.js。当前MODE是real，httpBaseUrl为http://127.0.0.1:18080，wsBaseUrl为空。启动不会自动登录、请求业务或建立Socket。
2. 电脑上先启动项目后端，再确认GET /api/health返回code=OK、application=UP、database=UP。健康成功只证明服务和数据库可用，不证明微信登录、权限或交付已通过。
3. 本机已有独立0.7/H2验收服务及启动脚本，具体入口见另存的《本机入口》；如果服务已健康，不要重复启动。重启服务会使现有登录凭据失效，但H2已提交的测试任务保留。
4. 完整编译后进入任务大厅，应显示“真实任务大厅需要微信登录”。从按钮进入微信登录；成功只返回原页面，不会自动发布、接单或完成任务。重新编译、凭据过期或后端重启后可能需要再次登录。
5. 手机需要后端同学提供可访问的测试服务地址及与小程序环境匹配的域名/HTTPS配置，再把演示副本的httpBaseUrl改为该地址并编译。手机的127.0.0.1指手机自身。没有可用地址时先用电脑模拟器，不在此临时修改安全设置或猜测域名。

AppSecret只放在后端本地私有配置，前端不需要也不应保存它。后端源码/依赖、启动、数据库和微信配置由后端运行说明负责；本包不附带这些私有运行文件。其他电脑需自行配置后端，不能依赖本机H2路径。

## 本地Mock展示

仅在演示副本把config/env.js的MODE改为mock并完整编译。顶部始终显示Mock样例，登录页只选虚构A/B/C，所有号码与说明使用虚构数据。展示完恢复real并完整编译。

Mock可展示大厅、发布样例、详情、我的任务、账号切换和样例收益。详情上的业务按钮部分仅演示预览；Mock交付码/扫码页明确不生成可扫描业务码，也不调用相机，不用它们替代真实扫码验收。切换模式和重新编译会丢失当前运行的Mock变化。

## 遇到问题

| 看到什么 | 怎么处理 |
| --- | --- |
| 后端健康失败/连接不上 | 先确认服务进程和地址；未完成健康检查前不反复登录 |
| 微信登录暂时不可用 | 由后端检查微信配置及到官方服务的连接，密钥不用发聊天 |
| 401或登录失效 | 使用原账号重新登录，不判断为被封禁 |
| 明确ACCOUNT_DISABLED | 联系管理员核对与恢复，不连续尝试绕过 |
| 已受理/结果待确认 | 接单用“确认原接单结果”，不要换编号或重新申请 |
| 发布结果未知 | 不重新提交；保留任务线索交后端核对，当前没有可靠跨重启发布找回协议 |
| 写入成功但详情更新失败 | 只重试查询，不再提交原写操作 |
| 无实时通知 | 当前F11未提供，使用页面返回/手动刷新；不是完整通知通过 |

发布、接单与交付会写入真实项目后端，只用明确的测试任务。没有真实付款、余额、提现功能。结束演示后记录任务编号和服务状态，不为清场删除未知归属数据。
