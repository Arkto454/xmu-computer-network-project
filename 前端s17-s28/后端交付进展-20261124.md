## 对接契约摘要

下表均要求学生 Bearer 凭据；管理员审核接口单独使用管理员凭据。

| 能力 | 方法与路径 | 请求/关键返回 | 前端阶段 |
| --- | --- | --- | --- |
| 我发布列表 | GET `/api/student/tasks/mine?page=1&size=20&status=WAITING` | 页码分页，摘要无私密信息 | S16-B |
| 抢单 | POST `/api/student/tasks/{id}/claim` | `{requestId, runnerPhone, runnerWechat}`；HTTP 202 表示 `PENDING`，不能提示已接单；确定结果后以相同 UUID、任务、表单重试 | S17/S18 |
| 我接单列表 | GET `/api/student/tasks/accepted?page=1&size=20&status=ACCEPTED` | 页码分页；详情以 `acceptedByMe` 标识关系 | S17/S19 |
| 确认取件 | POST `/api/student/tasks/{id}/pickup` | 无请求体；返回 `taskId, taskStatus, pickedUpAt` | S20 |
| 双方取消 | POST `/api/student/tasks/{id}/cancellations`；GET `.../cancellations/latest`；POST `.../cancellations/{cancellationId}/actions` | 创建用 UUID `requestId`；动作 `AGREE/DECLINE/WITHDRAW`；按角色和状态核验，部分取消需管理员审核 | 后续取消交互阶段 |
| 申请交付/读码 | POST `/api/student/tasks/{id}/delivery`；GET `.../delivery/code` | 返回 `taskId, codeVersion, codeStatus`；`ACTIVE` 时有 `expiresAt, imageBase64`，有效期 5 分钟 | S20 |
| 刷新/停用交付码 | POST `.../delivery/code/refresh`；POST `.../delivery/code/revoke` | 请求 `{codeVersion}`；冲突 `DELIVERY_CODE_CHANGED` 后先重新读取；停用不自动生成新码 | S20 |
| 扫码核验/确认 | POST `.../delivery/verify`；POST `.../delivery/confirm` | `{payload}`；核验与确认分开，确认时重新校验凭据 | S21 |
| 模拟收益 | GET `/api/student/earnings?page=1&size=20` | `items,totalAmount,total,page,size`，服务端分页汇总 | S22 |

任务 ID 为正整数；状态为英文枚举。任务详情含 `ownedByMe`、`acceptedByMe`、`pickedUpAt`、取消摘要、`completedAt`、`settlement` 和按关系授权的 `privateInfo`。二维码载荷与 requestId 都不得放 URL；交付图只按服务端 Base64/PNG 和到期时间展示。写操作超时需按各自协议处理，不把 HTTP 202、超时或未知结果表述成失败或成功。
