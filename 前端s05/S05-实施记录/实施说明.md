## 交付

| 文件 | 作用 |
| --- | --- |
| services/request.js | Promise封装wx.request，默认10秒超时；每次调用只发送一次；区分HTTP、业务、认证、网络、超时、协议与未知结果 |
| services/errors.js | 统一错误结构，保留HTTP状态、业务码、可读消息、调用方requestId与结果是否待确认 |
| services/index.js | 统一选择Mock或real，返回Promise；校验任务编号；real失败不回退Mock |
| services/mock.js | 复用原有两条公开样例，读取返回副本；不存在任务明确拒绝 |
| services/real.js | 任务契约未接入时明确拒绝，不猜测URL、字段和分页，不发送请求 |

请求解析器与凭据读取函数由适配器注入。无解析器、无必要凭据、地址或方法不合法时不发送。支持本项目所需的GET、HEAD、OPTIONS、POST、PUT、DELETE；不把微信请求层未支持的PATCH当作已实现能力。

写请求超时、断网、连接中断、HTTP5xx/408及异常成功响应都不能证明写入失败，统一保留待确认状态。认证错误仅分类，不在此层退出账号或跳转，避免提前实现不完整的会话逻辑。requestId只保留调用方元数据，不自动生成、替换、发送或持久化；完整幂等和找回原请求结果待后续契约。

详细行为表见《服务边界.md》，验证证据见《验收记录.md》《自动检查.json》。受控检查使用虚构格式`accepted/value/reason`，仅测试解析器接口，不是后端响应协议。
