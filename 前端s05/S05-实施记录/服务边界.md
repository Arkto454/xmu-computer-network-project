# S05 实施约定

默认Mock。request.js提供可注入传输、解析器与凭据读取入口的Promise客户端；没有解析器时请求不会发送。不假定后端code为0或success为true，也不创建未知业务URL。getToken仅预留凭据入口，S06负责会话代次、过期清理与一次跳转，S15接真实身份。

请求结果返回data、httpStatus、businessCode。错误保留kind、httpStatus、businessCode、requestId、outcome和resultUnknown；不保存响应正文、凭据或联系方式，不输出调试日志。

| 情况 | 分类 | 写操作结果 |
| --- | --- | --- |
| 地址、解析器、超时配置不完整 | configuration | not_sent |
| 受保护请求无凭据 | auth | not_sent |
| HTTP 401 | auth | rejected，不清理会话/跳转 |
| HTTP 403、404等4xx | http | rejected；408例外 |
| HTTP 5xx或408 | http | unknown，不能断言写入失败 |
| 超时/断网/连接中断/取消 | timeout或network | unknown |
| 2xx且解析器明确ok=false | business或auth | rejected；kind=unknown时unknown |
| 2xx格式不符/解析异常 | protocol | unknown |
| 2xx且明确ok=true | 成功 | 交由业务服务返回结果 |

GET/HEAD/OPTIONS视作查询。查询网络失败允许页面提供手动重试入口，但本层任何方法都不自动重试。不得用GET实施写操作。

requestId仅为调用方提供的关联元数据，不自动生成、不替换、不持久化，也不猜测传输字段。S08确认编号契约后，由业务服务明确放入请求体或约定头；S18再实现完整原请求恢复。当前错误中的requestId不等于已经完成幂等机制。

服务入口只根据环境选择一次Mock或real，不回退。Mock复用两条原有公开样例；real任务服务显式返回未接入，不联网。公开列表/详情返回Promise；无效taskId在调用提供者前拒绝。登录、发布、接单和扫码服务本轮不伪造实现。

本步是公共基础能力，页面沿用S04展示；S09/S10再将大厅/详情切换到本入口，并实现加载、筛选与页面并发控制。本轮不增加调试按钮，不改后端代码或两份项目配置。
